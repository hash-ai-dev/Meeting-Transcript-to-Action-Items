# Meeting Intelligence Application - Developer Walkthrough

This document explains the functionality and design of the **"Meeting Intelligence"** application. It is intended to be used by an AI agent to build a promotional React web page for this product.

## Application Overview

**Meeting Intelligence** is an AI-powered productivity tool designed to automatically extract actionable insights from meeting transcripts. It streamlines the post-meeting workflow by identifying tasks, owners, deadlines, and strategic notes, ensuring nothing gets lost in the noise.

## Key Features

1.  **AI-Powered Extraction**: Uses advanced natural language processing to parse unstructured meeting text.
2.  **Action Item Tracking**: Automatically identifies tasks, assigns owners, and sets deadlines.
3.  **Strategic Notes**: capturing important decisions and context that aren't direct tasks.
4.  **Session Management**: Save, load, and manage multiple meeting contexts effortlessly.
5.  **Modern UI**: A clean, "Cofounder-style" interface with glassmorphism effects and a focus on readability.
